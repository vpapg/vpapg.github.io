# Static academic website

Files are ready for GitHub Pages and local `file://` preview.

- Three colour themes: Light, Reading, Dark.
- Theme persists across pages online and is carried in local file links during direct browser preview.
- All navigation/content links open in a new tab. The **Skip to main content** link intentionally remains same-page for accessibility.
- Replace or copy your existing `media/`, `syllabi/`, and `posts/` folders alongside these files.
